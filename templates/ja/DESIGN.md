# DESIGN.md — レイヤーのデザインルール

room をまたいで共有するものをここに置きます。トークン、コンポーネント、アクセシビリティの
下限です。room はこのファイルから取り、取ったものを `SPEC.md`（`使ってよいもの:` の行）に
書きます。ここにある色・文字サイズ・ボタンを room 側で作り直してはいけません。2つの room が
同じ判断を繰り返すなら、ここへ移して参照します — 両方にコピーしてはいけません。

artifact はビルド手順のない素の HTML なので、トークンは CSS カスタムプロパティです。
小さく保ってください。デザインレイヤーはコンポーネントライブラリではありません。下の値は
プロジェクト自身のものに一度だけ置き換えます。

## デザインシステム

このレイヤーがどのデザインシステムから描くのか、その正がどこにあるのかを書きます。agent は
マークアップを書く前に何を読むべきかを知れます。

- **正:**（パッケージ、URL、Figma ファイルなど、コンポーネントとトークンの定義がある場所）
- **MCP:**（agent が Model Context Protocol 経由で読む場合のサーバ名。なければ "none"）

MCP サーバの**設定**はここではなく `opencode.json` に書きます。agent はこのディレクトリで
動くので、OpenCode は `modelroom/opencode.json` を読みます。このファイルはどのサーバが
大事かを示すだけです。秘密情報は環境変数に置き、どちらのファイルにも書きません。

## コンポーネント

2つの room が共有するもの — ボタン、入力欄、バッジ — はここに一度だけ書きます。マークアップ、
状態、使うトークンです。room は `SPEC.md` からそれを参照します。変化が要る room は、その
`SPEC.md` にそう書きます。コンポーネントを分岐させず、ここに書き直しもしません。

## アクセシビリティの下限

- コントラスト: 本文は WCAG AA（4.5:1）、大きい文字と UI は 3:1。
- すべての操作要素は、キーボードだけで到達・操作できる。
- フォーカスを見えるようにする — 代替なしに outline を消さない。
- 指で操作する場所では、タッチ対象は最低 44×44px。

## このファイルではないもの

- room ではありません。1画面だけが必要とする判断は、その room の `SPEC.md` に置きます。
- artifact ではありません。スクリーンショットで見えるものは `index.html` に属します。ここには
  画面を描くためのトークンと、その背景にある理由を置きます。
